# Claude Code Project Configuration

## Security Testing Multi-Agent Framework

Production-ready penetration testing orchestrator with 101 specialized agents across 30 sequential phases.

### Framework Highlights

- **101 specialized agents** across 30 sequential phases
- **150+ integrated Kali Linux tools** via SSH
- **Claude Code Agent dispatch** (no external API)
- **4-layer validation** (Format → Evidence → Technical → Remediation)
- **0% false positive guarantee** with real evidence
- **CVSS 3.1 scoring** with OWASP/CWE/MITRE mapping
- **Secure credential management** (.secrets git-ignored)
- **~2 hour full penetration test**

---

## How to Use with Claude Code

### Quick Start

In Claude Code, ask:
```
"Run full penetration test for my-client"
```

The orchestrator will:
1. Load engagement config and credentials from `.secrets`
2. Execute 101 agents across 30 phases sequentially
3. Validate all findings through 4-layer validation gates
4. Generate professional HTML report with CVSS scores and remediation

### Key Files

- `orchestrator/Orchestrator.js` — Main orchestration engine (500+ lines)
- `orchestrator/agents/` — 101 agent specification files
- `docs/Master-Documentation-Portal.html` — Interactive documentation
- `docs/DOCUMENTATION.md` — Comprehensive guide (20,000+ lines)
- `engagements/template/` — Template for new engagements

### Setup (One-Time)

```bash
# 1. Clone repository
git clone https://github.com/UsamaArshadJadoon/SecurityTestingMultiAgentWithKali.git
cd SecurityTestingMultiAgentWithKali

# 2. Setup Kali tools (30 minutes)
bash kali-setup/kali-init.sh
bash kali-setup/install-tools.sh

# 3. Create new engagement
bash scripts/setup-engagement.sh my-client

# 4. Add credentials
nano engagements/my-client/.secrets

# 5. Update scope
nano engagements/my-client/scope.md
```

### Run Penetration Test in Claude Code

```
Me: "Run full penetration test for my-client"

Claude: Orchestrating 101 agents across 30 phases...

[Phase 2: Web Application]

✅ Agent-002B: XSS Testing
... [continues through all 30 phases]

[Phase 30: Reporting]

Report: engagements/my-client/report/report.html
```

## 4-Layer Validation System

Every finding passes through:

1. **Format Validation** — Valid JSON, all required fields, correct types
2. **Evidence Validation** — Real HTTP requests/responses, tool output, screenshots, reproducible steps
3. **Technical Accuracy** — CVSS justified, specific impact, no vague language
4. **Remediation Validation** — Code examples (vulnerable + fixed), clear steps, realistic effort

**Result:** 0% false positive rate with 100% developer-ready findings

## Troubleshooting

### Agent Timeout
Increase in Orchestrator.js:
```javascript
const AGENT_CONFIG = {
  timeout: 7200,  // 2 hours
};
```

### Missing Credentials
Verify `.secrets` exists and has all required fields:
```bash
cat engagements/my-client/.secrets
```

### Kali Tools Not Found
Reinstall tools:
```bash
bash kali-setup/install-tools.sh
```
