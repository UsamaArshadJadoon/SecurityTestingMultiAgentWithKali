# Claude Code Project Configuration

## Security Testing Multi-Agent Framework

This project uses Claude Code for development and orchestration of 31 penetration testing agents.

### Setup for Claude Code

1. **Copy this to root:** `.claude/CLAUDE.md`
2. **Claude Code will auto-detect** this project configuration
3. **Agents run via:** `Agent` tool with specialized agent types

---

## Framework Overview

- **31 agents** across 13 sequential phases
- **Hyper-V Kali VM** integration via SSH
- **Claude API** dispatches each agent
- **Sequential execution** with context passing

---

## How to Use with Claude Code

### Quick Start
```bash
# In Claude Code terminal:
cd SecurityTestingMultiAgentWithKali
node orchestrator/workflow.js my-engagement-name
```

### Key Files
- `orchestrator/workflow.js` — Main orchestrator
- `orchestrator/agents/*.md` — Agent specifications
- `.claude/agents/` — Agent definitions for Claude Code
- `engagements/template/` — Copy for new engagement

### Environment Setup
```bash
# Setup Kali VM (one-time)
bash kali-setup/kali-init.sh
bash kali-setup/install-tools.sh

# Verify setup
bash orchestrator/kali-health-check.sh

# Create new engagement
bash scripts/setup-engagement.sh my-client-name

# Run pentest
bash scripts/run-pentest.sh my-client-name
```

### Claude Code Agent Types Available

This project uses:
- `penetration-tester` — For active exploitation agents
- `security-auditor` — For vulnerability analysis agents
- `code-reviewer` — For source code review agents
- `general-purpose` — For flexible agents

## Project Structure

```
orchestrator/
  ├─ workflow.js           # Main orchestrator (calls agents)
  ├─ agents/               # Agent specs (31 agents)
  └─ kali-wrapper.sh      # SSH to Kali VM

kali-setup/
  ├─ kali-init.sh         # Bootstrap Kali VM
  ├─ install-tools.sh     # Install 55+ tools
  └─ kali-config.yaml     # SSH configuration

.claude/
  ├─ agents/              # Claude Code agent configs
  ├─ settings.json        # Claude Code settings
  └─ hooks/               # Post-commit hooks (optional)

engagements/
  └─ template/            # Copy for new engagement
```

## Running Agents via Claude Code


## Troubleshooting

### Kali VM Not Reachable
```bash
# Check Kali is running:
bash orchestrator/kali-health-check.sh

# Verify SSH keys:
ls -la .claude/ssh-keys/
```

### Agent Timeout
```bash
# Increase timeout in orchestrator/workflow.js:
const AGENT_TIMEOUT = 7200  // 2 hours
```

### Missing Findings
```bash
# Check evidence directory:
ls -la engagements/my-engagement/evidence/findings/
```
