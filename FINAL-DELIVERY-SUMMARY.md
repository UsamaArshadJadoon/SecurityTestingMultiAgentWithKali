## 🚀 DEPLOYMENT MODEL

### **How It Works:**

```
1. Clone repository
   └─> SecurityTestingMultiAgentWithKali

2. Setup (one-time)
   ├─ bash kali-setup/kali-init.sh
   └─ bash kali-setup/install-tools.sh

3. In Claude Code, create engagement
   └─ bash scripts/setup-engagement.sh my-client

4. In Claude Code, run agents sequentially
   ├─ "Run recon-agent for my-client"
   ├─ "Run web-pentest-agent for my-client"
   ├─ "Run api-security-agent for my-client"
   ├─ ... [all 31 agents] ...
   └─ "Run reporting-agent for my-client"

5. View final report
   └─ engagements/my-client/report/report.html
```

### **Why Claude Code?**

✅ **Native Agent Tool** - Dispatch all 31 agents without external API  
✅ **Local Control** - Everything runs on your machine  
✅ **No Dependencies** - No cloud, no authentication needed  
✅ **Full Automation** - Sequential execution with data flow  
✅ **VS Code Integration** - Edit configs and view results easily  
✅ **Kali SSH** - Direct access to Hyper-V Kali VM tools
