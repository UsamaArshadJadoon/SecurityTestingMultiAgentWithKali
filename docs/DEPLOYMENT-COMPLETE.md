## 🎓 HOW TO USE

### **For End Users (Security Professionals)**

```bash
# 1. Clone repository
git clone https://github.com/UsamaArshadJadoon/SecurityTestingMultiAgentWithKali.git
cd SecurityTestingMultiAgentWithKali

# 2. Open beautiful getting started guide
# Open docs/GETTING-STARTED.html in web browser
# (Professional design with animations)

# 3. Install tools (one-time setup, 30 minutes)
bash kali-setup/kali-init.sh
bash kali-setup/install-tools.sh

# 4. Create new engagement
bash scripts/setup-engagement.sh my-target

# 5. Add credentials and configuration
nano engagements/my-target/.secrets
nano engagements/my-target/scope.md

# 6. Run penetration test (in Claude Code)
# Open claude-code and type:
# "Run full penetration test for my-target"

# 7. Review professional HTML report
open engagements/my-target/report/report.html
```
