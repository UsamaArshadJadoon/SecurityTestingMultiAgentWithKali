🚀 Installation Guide

Step-by-step setup for Security Testing Multi-Agent Framework

⏱️ Estimated time: 15-20 minutes

1

Clone Repository

Download the framework from GitHub

Clone the Security Testing Multi-Agent Framework repository to your local machine using Git.
git clone https://github.com/UsamaArshadJadoon/SecurityTestingMultiAgentWithKali.git cd SecurityTestingMultiAgentWithKali
💡 Tip: Make sure you have Git installed. Download from git-scm.com if needed.
2

Verify Prerequisites

Check your system requirements

Ensure your system has all required software and meets the minimum requirements.
Node.js 16+
Python 3.8+
Git 2.20+
4GB RAM minimum
20GB Disk Space
Docker (optional)
node --version python3 --version git --version docker --version
3

Install Dependencies

Install Node.js and Python packages

Install all required Node.js packages and Python dependencies for the framework.
npm install pip install -r requirements.txt
⚠️ Note: This may take a few minutes depending on your internet connection.
4

Setup Kali VM (Optional)

Configure Hyper-V Kali Linux for SSH access

If you plan to use the integrated Kali Linux tools, set up a Kali VM with SSH access. This is optional - the framework works with local tools too.
bash kali-setup/kali-setup-complete.sh
📝 Instructions: Follow the prompts to configure your Kali VM SSH connection details.
5

Create Engagement

Setup your first security testing engagement

Create a new engagement directory with configuration templates for your target application.
bash scripts/setup-engagement.sh my-client-app
ℹ️ Info: Replace 'my-client-app' with your actual target application name.
6

Configure & Run

Configure credentials and start testing

Configure your target credentials in the .secrets file and validate your configuration before running the framework.
nano engagements/my-client-app/.secrets bash scripts/validate-config.sh my-client-app
🔒 Security: The .secrets file is git-ignored and never committed to the repository.
✨

Installation Complete!

You're now ready to run security tests. Start with the Interactive Agent Directory to explore all 31 agents.
