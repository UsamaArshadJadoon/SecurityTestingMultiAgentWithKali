Installation & Setup

Get running in minutes with our streamlined process.

Requirements

  • Kali Linux VM: 4GB RAM, 20GB disk, SSH port 22
  • Host System: Windows, macOS, or Linux
  • Claude Code: Latest version
  • Python: 3.8+
  • Node.js: 14+

Quick Start

git clone https://github.com/UsamaArshadJadoon/SecurityTestingMultiAgentWithKali.git
cd SecurityTestingMultiAgentWithKali && bash kali-setup/kali-init.sh
bash scripts/setup-engagement.sh my-target
nano engagements/my-target/.secrets
bash scripts/validate-config.sh my-target

In Claude Code:

"Run full penetration test for my-target"
