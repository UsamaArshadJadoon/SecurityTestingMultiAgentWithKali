Installation & Setup

Get up and running in minutes with our streamlined setup process.

System Requirements

  • Kali Linux VM: 4GB RAM, 20GB disk space, SSH port 22 accessible
  • Host System: Windows, macOS, or Linux with SSH client
  • Claude Code: Latest version (https://claude.com/code)
  • Python: 3.8 or newer
  • Node.js: 14 or newer
  • Git: 2.25 or newer

Quick Start (5 minutes)

git clone https://github.com/UsamaArshadJadoon/SecurityTestingMultiAgentWithKali.git
cd SecurityTestingMultiAgentWithKali && bash kali-setup/kali-init.sh
bash scripts/setup-engagement.sh my-target
nano engagements/my-target/.secrets
bash scripts/validate-config.sh my-target
