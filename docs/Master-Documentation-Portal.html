✅ 4-Layer Validation System

Every finding goes through rigorous validation to ensure 0% false positives and 100% accuracy.

1

Format Validation

Verify JSON schema compliance, all required fields present, correct data types, no missing information

2

Evidence Validation

Real HTTP request/response pairs, authentic tool output, genuine screenshots, reproducible steps

3

Technical Accuracy

CVSS score mathematically justified, specific impact (not "could potentially"), no fabrication language, correct vulnerability type

4

Remediation Validation

Vulnerable code example, fixed code example, clear remediation steps, developer-friendly explanations

❓ Frequently Asked Questions

How do agents communicate?

Agents are dispatched sequentially through phases using Claude Code's Agent tool. Each agent receives findings from the previous agent as context, ensuring data continuity across phases.

How is credential security ensured?

Credentials are stored in `.secrets` files that are git-ignored. Agents load credentials at runtime only, never log them, and all credentials are automatically masked in findings before report delivery.

What if an agent finds nothing?

This is normal and expected. Agents report "No vulnerabilities found in this area" and the framework continues to the next phase. The final report aggregates findings from all phases.

Can I modify agents?

Yes! Each agent is defined in `orchestrator/agents/` folder. You can modify prompts, add tools, change validation rules. Restart the orchestrator for changes to take effect.

How long does a full test take?

Typically 1.5 to 2.5 hours depending on target complexity. Reconnaissance and surface testing are fastest. Deep exploitation and business logic testing take longer.

What happens if an agent crashes?

The orchestrator has automatic retry logic. If an agent fails 3 times, it's skipped with a warning in the final report. Critical agents (reconnaissance, reporting) have enhanced retry logic.

Can I run specific phases?

Yes. Use the orchestrator's phase selection: "Run phase 1-3 for reconnaissance and surface testing only" to skip later phases.

How accurate are findings?

Very accurate. Every finding passes 4 validation layers. The framework has a 0% false positive policy. All findings include real evidence, reproducible steps, and working code fixes.

What if I find a bug in an agent?

Report it in GitHub issues or contact the maintainers. Include the agent name, test target, and reproduction steps.

Is this framework suitable for production?

Yes. It's designed for enterprise use with security-hardened code, comprehensive logging, audit trails, and professional reporting suitable for C-level stakeholders.
