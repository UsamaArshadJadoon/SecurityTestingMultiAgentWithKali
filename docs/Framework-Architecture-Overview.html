1

Engagement Setup

User provides target URL, credentials, scope, and roles via .secrets file

2

Orchestrator executes 13 sequential phases with proper data flow between them

3

Agent Execution

31 specialized agents run in parallel within each phase using integrated tools

4

Candidate Generation

Agents generate raw findings with evidence from actual testing

5

Validation Pipeline

4-layer validation gates process findings for quality and accuracy

6

Sanitization

Credentials and PII are automatically masked before reporting

7

Critical findings (CVSS 7.0+) require security lead approval

8
