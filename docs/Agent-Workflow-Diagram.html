📊 Complete Data Flow Architecture

1
Engagement Configuration
User provides target URL, credentials, scope, and roles via .secrets file
2
Reconnaissance Phase (Agent 1)
Asset discovery and fingerprinting → Surface Map (JSON)
3
Surface Testing Phase (Agents 2-7)
Parallel agents test web, API, auth, infra, cloud, AI → Candidate Findings
4
Validation Gate 1 (Format)
Validate JSON schema, required fields, ID format → Pass/Fail findings
5
Deep Exploitation Phase (Agents 8-14)
Advanced exploitation chains → Enhanced Findings with proof-of-concept
6
Validation Gate 2 (Evidence)
Verify real HTTP requests, authentic tool output, genuine evidence → Authentic findings
7
Post-Exploitation Phase (Agents 15-18)
Privilege escalation, lateral movement, secrets harvesting → System Compromise data
8
Source Code & Cloud Testing (Agents 19-23)
Code disclosure, Git analysis, AWS/GCP/Azure testing → Source & Cloud Findings
9
Validation Gate 3 (Technical Accuracy)
Verify CVSS justification, vulnerability type, no fabrication → Technically sound findings
10
Advanced Testing (Agents 24-34)
Auth, crypto, supply chain, business logic, protocols, chaining → Complex Findings
11
Validation Gate 4 (Remediation)
Verify code examples, clear steps, effort estimates → Actionable findings
12
Human Approval Gate
Security lead review of CVSS 7.0+ findings → Approved findings
13
PII Masking & Sanitization
Mask credentials, PII, sensitive data → Safe findings
14
Reporting Phase (Agent 35)
Aggregate findings, generate HTML report, CVSS/OWASP/CWE mapping → Client-ready report
