⚙️ Initial Setup

1 Create Kali Linux Hyper-V VM

If you haven't created a Kali VM yet:

Download Kali Linux Hyper-V Image: https://www.kali.org/get-kali/
  1. Extract the downloaded file
  2. Open Hyper-V Manager
  3. Import the Kali VM from the extracted folder
  4. Start the VM
  5. Login with default credentials (kali:kali)

2 Configure Hyper-V Network (Bridge Mode)

To communicate with Windows machine on same network:

# On Hyper-V Manager (Windows Host): 1. Open Hyper-V Manager 2. Click "Virtual Switch Manager" (right panel) 3. Create "External" switch 4. Name it: "Bridge Network" 5. Select your physical network adapter 6. Click Apply # Result: Kali VM gets IP on your network (192.168.x.x)

3 Install SSH Server on Kali VM

Connect to Kali VM console and run:

sudo apt-get update sudo apt-get install -y openssh-server openssh-client sudo systemctl start ssh sudo systemctl enable ssh # Verify SSH is running: sudo systemctl status ssh # Output: active (running) ✓

4 Install Framework on Kali VM

cd /home/kali git clone https://github.com/your-org/SecurityTestingMultiAgentWithKali.git cd SecurityTestingMultiAgentWithKali npm install # Verify installation: npm test
✅ Framework installed and ready!

🔌 SSH Connection Setup

1 Find Kali VM IP Address

In Kali VM Terminal, run:

hostname -I # Output: 192.168.1.100 ifconfig # Look for "inet 192.168.x.x"
Note: Write down this IP address. You'll need it to connect from Windows.

2 Install SSH Client on Windows

Option A: Built-in OpenSSH (Windows 10+)

# In PowerShell (Admin): Add-WindowsCapability -Online -Name OpenSSH.Client~~~~0.0.1.0 # Verify installation: ssh -V # Output: OpenSSH_for_Windows_8.1p1

Option B: Download Git Bash (Easiest)

Download from: https://git-scm.com/download/win
Includes SSH automatically

3 Connect from Windows to Kali VM

Using PowerShell:

ssh kali@192.168.1.100 # First time, you'll see: The authenticity of host '192.168.1.100' can't be established. Are you sure you want to continue connecting? (yes/no/[fingerprint]) Type: yes # Enter password when prompted: kali@192.168.1.100's password: •••••••• # Enter: kali (default password) # Success! You're now connected to Kali VM: kali@kali:~$

4 Test SSH Connection

Verify you're connected to Kali VM:

whoami # Output: kali uname -a # Output: Linux kali ... x86_64 cat /etc/os-release | grep NAME # Output: NAME="Kali GNU/Linux"
✅ SSH Connection Established!

🔧 Troubleshooting Guide

❌ Cannot Connect to Kali VM

Error: "ssh: Could not resolve hostname 192.168.1.100"

Cause: Network connectivity issue or wrong IP address

✅ Solution:
1. Get correct IP from Kali VM: hostname -I
2. Test connectivity from Windows: ping 192.168.1.100
3. Check Hyper-V network settings: External switch configured?
4. Verify Kali VM has network adapter attached

❌ Permission Denied (password incorrect)

Error: "Permission denied, please try again"

Cause: Wrong password or username

✅ Solution:
1. Default credentials: username=kali, password=kali
2. Case sensitive - try again carefully
3. If still failing, reset password in Kali VM console

❌ SSH not installed on Windows

Error: "ssh: command not found"

✅ Solution:
Option A: Install OpenSSH via Settings
Option B: Download Git Bash (https://git-scm.com/)
Option C: Use PuTTY as GUI alternative

❌ Assessment Timeout

Error: "Assessment timeout after 3600000ms"

✅ Solution:
1. Select faster intensity: Rapid instead of Thorough
2. Increase timeout: ASSESSMENT_TIMEOUT=7200000 npm run assess
3. Check network: high latency can cause timeouts

❌ Report not generated

Error: "report-*.json not found"

✅ Solution:
1. Check assessment completed: was there a success message?
2. List all files: ls -la
3. Check logs: tail -f logs/app.log
4. Re-run assessment with verbose logging
